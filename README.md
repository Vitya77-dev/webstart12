# APEX — учебный сайт

Русская версия статического сайта о программе APEX. Оформление и основные разделы сохранены; реальные продажи отключены.

## Как открыть

Откройте `index.html` в браузере. Для проверки по HTTP можно запустить из папки проекта:

```sh
python -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Сценарий демонстрации

1. Главная страница знакомит с темами программы.
2. Анкета показывает ориентировочный расчёт в сантиметрах. Имя и почта необязательны; данные никуда не отправляются.
3. В разделе оплаты указана цена «Символическая». Это место стоимости в коммерческом продукте; сейчас материалы выдаются бесплатно.
4. Кнопка «тут оплата» открывает `Payment.html` в новой вкладке.
5. На странице доступны шесть бесплатных PDF и общий ZIP. Платёжных форм и возможности покупки нет.

Раздел помощи объясняет скачивание и работу с анкетой. Форм отправки писем и внешнего сбора данных нет.

## PDF

Файлы размещены в `assets/pdf/`. Исходные коммерческие PDF в проекте отсутствовали, поэтому подготовлен новый комплект по темам сайта. Условность учебного задания описана только в этой документации; в интерфейсе и пособиях таких надписей нет. Материалы не являются медицинской программой.

- `apex-program.pdf` — структура программы и лист планирования.
- `nutrition-notes.pdf` — питание и вопросы о добавках.
- `visual-guide.pdf` — сравнение визуальных образов.
- `sleep-journal.pdf` — дневник сна.
- `daily-checklist.pdf` — ежедневный чек-лист.
- `progress-tracker.pdf` — трекер на 12 недель.
- `apex-materials.zip` — все шесть PDF.

Генератор: `scripts/build-pdfs.py` (Python, ReportLab, шрифты Arial из Windows). Готовые PDF уже включены в проект; для работы сайта Python не нужен.

Для отображения шрифтов сайт обращается к Google Fonts; при отсутствии интернета используются системные шрифты. Анкета и скачивание не используют сторонние API.
